# =============================================================================
# Backup coverage allowlist | 备份覆盖率白名单
# =============================================================================
# Read by scripts/check-backup-coverage.py. Every template/copy task that
# writes under /etc must set `backup: true`. A task that genuinely must not
# keep a backup is exempted here, never by silently omitting the option.
#
# Format: one entry per line
#
#   <repo-relative path>:<task name>
#
#   * path  - POSIX path relative to the repository root, e.g.
#             roles/nginx/tasks/main.yml. Shell globs are allowed (fnmatch),
#             e.g. roles/lifecycle/tasks/hooks/*.yml
#   * task  - the exact `name:` of the task (globs allowed as well). Unnamed
#             tasks are reported as <unnamed>; give them a name instead.
#   * Everything after `#` at the start of a line is a comment. Document the
#     reason for the exemption in a comment directly above the entry.
#
# Unused entries are reported as warnings so stale exemptions get removed.
# =============================================================================

# Static console assets copied from the upstream release tarball (directory
# sync with remote_src); they are never edited on the host, so a backup has no
# rollback value and the directory copy does not support per-file backups.
roles/prometheus/tasks/install.yml:Install console templates and libraries*

# Secret cache file (0600). The role regenerates it from V2BX_AUTH_KEY or the
# panel when missing, so a backup has no rollback value; the exemption only
# avoids authkey.<pid>.<timestamp>~ copies piling up next to the live key. It
# does NOT keep old AuthKeys out of every backup: the key is also embedded in
# config.json, whose backups (config.json.<pid>.<timestamp>~, 0600 root:root in
# the 0750 /etc/V2bX, needed by the role's rescue and by rollback.yml) and the
# lifecycle snapshots of v2bx_backup_files (0700 /var/backups/v2bx, lifecycle
# retention) keep superseded keys. The AuthKey is a short-lived registration key
# (v2bx_authkey_expire_days, default 1); revoke a leaked key on the panel.
roles/v2bx/tasks/authkey.yml:Store the AuthKey on the node for future runs*
